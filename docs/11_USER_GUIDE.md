# 用户指南

## 1. 启动应用

在项目目录运行：

```powershell
python -m streamlit run app.py
```

浏览器打开 `http://127.0.0.1:8501/`。首次启动会自动创建本地数据库。

## 2. 第一次使用

1. 进入“设置”，填写每天可用于工作、学习和生活的分钟数，以及提醒时间。
2. 进入“目标与方向”，把示例内容改成你自己的长期方向和当前目标。
3. 进入“习惯”，通过新增入口添加你希望每天记录的习惯。
4. 进入“任务”，添加一次性任务或每天都要做的任务。

## 3. 设置“每天睡眠 8 小时”

可以保留两个互补记录：

### 作为每日任务

1. 打开“任务”。
2. 选择添加每日任务。
3. 标题填写“保持 8 小时睡眠”。
4. 验收标准写清楚，例如“实际睡眠达到 480 分钟”。
5. 根据你的容量口径决定是否计入可支配时间。

系统每天会生成一个任务实例。停止每日任务后，只停止未来生成，过去记录不会消失。

### 作为习惯

1. 打开“习惯”。
2. 点击新增习惯。
3. 名称填写“睡眠 8 小时”，目标分钟填写 `480`。
4. 每天记录实际分钟和备注。

任务回答“今天是否安排和完成”，习惯回答“长期是否稳定做到”。两者可以同时存在。

## 4. 推荐每日用法

### 早晨：选择重点

- 打开“今日”，看主任务和容量。
- 需要提前规划时点击“明日安排”；查询过去或更远的日期时使用右侧日期查询。
- 保留真正必须完成的少量任务。
- 临时发现一个明确任务时，可用今日页快速添加。

### 白天：执行与记录

- 完成后立即勾选，并填写真实投入分钟。
- 确实做不完时使用顺延，不要用“完成”掩盖未完成。
- 习惯页记录睡眠、运动、阅读等实际情况。
- 阅读页记录页数、分钟和真正改变认知的内容。

### 晚上：复盘

- 在“复盘”中先写事实，再写判断。
- 记录最大的收获、问题和明日主任务。
- 查看统计，但不要为追求完成率创建没有价值的小任务。

## 5. 页面说明

| 页面 | 用途 |
|---|---|
| 今日 | 今日计划、明日安排、日期查询、Focus、任务时间轴、习惯与一天一页记录 |
| 目标与方向 | 长期方向、目标层级和进度 |
| 任务 | 完整创建、编辑、筛选、顺延、完成和每日模板管理 |
| 阅读 | 书单进度与阅读日志 |
| 习惯 | 新增习惯、当天打卡、分钟和连续天数 |
| 复盘 | 一日一条结构化复盘 |
| 数据统计 | 任务分类、完成率、投入和学习连续天数 |
| 设置 | 容量、提醒时间和主题偏好 |

## 6. 当前暂不支持

- Quick Capture 未分类收件箱；
- 独立 Daily Journal 历史和全文搜索；
- Goal History；
- 习惯编辑/删除/停用；
- 书籍新增/删除/排序；
- 操作系统通知、云同步和手机 App。

“今日快速添加”会直接创建任务，不能代替 Quick Capture。

## 7. 数据在哪里

所有业务数据默认保存在 `data/growth.db`。它包含目标、任务、习惯、阅读和复盘，属于敏感个人数据。请定期备份；不要随意删除、覆盖或上传。

完整操作见 [12_DATA_AND_BACKUP.md](12_DATA_AND_BACKUP.md)。

## 8. 常见问题

### 为什么刷新后多了每天的任务？

启用的每日任务模板会在当天首次加载时生成实例。同一天重复刷新不会继续重复生成。

### 为什么没有收到系统通知？

当前提醒只显示在正在运行的应用页面内，不是 Windows 系统通知。

### 如何停止一个每日任务？

在任务页停用相应模板。历史实例保留，未来不再生成。

### 页面报数据库错误怎么办？

先停止操作并保留现场，不要重建数据库。备份当前 `growth.db`，保存终端报错，再按恢复文档检查。
