# 测试与验收计划

## 1. 测试目标

验证用户数据不丢失、核心日常流程可用、统计口径可信，以及新增功能不会破坏现有任务/习惯/阅读/复盘流程。

## 2. 当前自动化测试

| 范围 | 文件 | 主要覆盖 |
|---|---|---|
| 数据与 service | `tests/test_core.py` | 默认初始化、每日任务幂等物化、任务状态、容量、习惯连续、阅读、规划、提醒 |
| 页面烟雾 | `tests/test_ui.py` | 8 个当前页面可以通过 Streamlit AppTest 启动 |
| 数据安全 | `tests/test_data_safety.py` | 新库版本、旧库迁移前备份、数据保留、手工备份、损坏库拒绝迁移 |

当前自动化测试不是完整 E2E：它不能替代真实浏览器中的布局、表单交互和数据恢复检查。

当前共 13 项自动化测试。`tests/conftest.py` 强制 UI 测试使用 `tests/runtime/app-test.db`，避免测试写入真实数据库。

## 3. 本地执行

```powershell
python -m pytest -q -p no:cacheprovider --basetemp tests/runtime
```

测试必须使用临时数据库，不能指向 `data/growth.db`。如果 `tests/runtime` 被其他进程锁定，应先确定占用原因，不要删除真实数据目录。

## 4. 当前核心验收矩阵

| 场景 | 操作 | 预期结果 |
|---|---|---|
| 首次启动 | 在空的临时数据库初始化 | 所有表创建，默认设置存在，不重复插入 |
| 每日睡眠任务 | 新建每日睡眠模板并物化同一天两次 | `tasks` 中只有一个当天实例 |
| 普通任务 | 今日页快速创建 | 保存为用户任务，显示在当天列表并计入容量 |
| 任务完成 | 填实际分钟后完成 | 状态、完成度、完成时间和分钟一致 |
| 顺延 | 顺延到明天 | 日期变化，顺延次数加一，其他字段保留 |
| 停止每日任务 | 停用模板后物化明天 | 历史实例保留，明天不再生成 |
| 习惯打卡 | 同一天重复保存 | 更新同一条日志，不产生重复记录 |
| 阅读记录 | 登记分钟和页数 | 日志创建，书籍总分钟和页数正确 |
| 每日复盘 | 同一天保存两次 | 第二次更新当天记录，不重复 |
| 容量建议 | 当天预计分钟超过可用分钟 | 显示超载及可执行建议 |
| 页面启动 | 打开 8 个导航页面 | 无未捕获异常，空状态可理解 |

## 5. 异常与边界测试

- 空标题、负分钟、非法时间、超过 100 的进度必须被拒绝。
- 重复习惯名、书名、每日模板名应显示冲突原因。
- 删除父目标后，任务和子目标数据仍可读取，关联按约束置空。
- 2 月 29 日、跨年、月末顺延等日期边界正确。
- 数据库只读、磁盘满或文件被锁定时，UI 不显示假成功。
- 多次刷新今日页不会重复生成每日任务。
- 已完成任务不应继续被选为今日主任务。

## 6. 数据迁移测试

每次 Schema 变更必须准备：

1. 当前 Schema 的空库；
2. 旧版本结构且带代表性数据的数据库副本；
3. 已是新版本的数据库。

分别执行初始化/升级两次，验证版本记录、行数、外键、唯一约束和应用启动。升级失败后检查原副本可恢复。严禁在唯一的用户数据库上首次试迁移。

V0.2 已自动覆盖空库、无版本记录的旧库、已是当前版本的数据库和损坏数据库；真实恢复演练仍需用户在明确确认后执行。

## 7. 未来功能验收

### Daily Journal

- 按日期保存和读取一致；
- 历史列表排序正确；
- 搜索不会漏掉中文内容；
- 与现有复盘的关系清晰且旧数据可访问。

### Quick Capture

- 三秒内完成捕获；
- 转任务/日记成功后状态正确；
- 转换写入失败时原捕获仍在收件箱；
- 重复点击不会生成重复目标记录。

### Goal History

- 每次重要更新同时产生版本；
- 版本内容能复原当时状态；
- 归档不破坏任务关联；
- 版本写入失败时目标主记录不应单独更新。

## 8. 手工 UI 验收

1. 使用测试数据库启动应用。
2. 按“早晨—白天—晚上”完整走一遍日常流程。
3. 检查桌面与窄屏布局、按钮反馈、空状态、错误提示。
4. 重启应用，确认刚写入的数据仍存在。
5. 执行一次备份并从副本验证能打开。

## 9. 发布门槛

- 自动化测试全部通过；
- 数据迁移已在副本验证；
- 关键手工流程通过；
- 没有未说明的数据破坏风险；
- README、需求状态、数据库设计和 CHANGELOG 已同步；
- 未验证项明确列出，不能声称完成。
