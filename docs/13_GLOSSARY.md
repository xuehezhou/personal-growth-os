# 术语表

| 术语 | 含义 |
|---|---|
| Personal Growth OS | 把目标、行动、习惯、阅读和复盘连接起来的个人成长系统 |
| CRUD | Create、Read、Update、Delete，即新增、读取、修改、删除四类基本数据操作 |
| 今日任务 | `planned_date` 为当天的一次任务记录 |
| 每日任务 | 每天自动生成任务实例的模板，不是永远复用同一条任务 |
| 任务实例 | 某个具体日期可完成、顺延或放弃的 `tasks` 记录 |
| 验收标准 | 判断任务是否真正完成的可观察条件 |
| 必做任务 | `must_today=1` 的当日优先任务 |
| 容量 | 当天可用分钟与计入容量的预计任务分钟之间的关系 |
| 主任务 | 规则选出的当天最重要未完成任务；不是自动替用户做决定 |
| 目标层级 | 长期、阶段、周三个当前层级 |
| Goal History | 目标修改前后的版本、原因和时间；当前尚未实现 |
| Habit | 需要长期重复并按天记录的行为 |
| Habit Log | 某个习惯在某一天的完成、分钟和备注 |
| Reading Log | 某次阅读的分钟、页数、收获和应用记录 |
| 每日复盘 | 当前一日一条的结构化回顾，保存在 `daily_reviews` |
| Daily Journal | 更完整的日记记录、历史、搜索和标签能力；当前只部分满足 |
| Quick Capture | 先保存、后分类的快速收件箱；当前未实现 |
| 物化 | 根据每日模板创建某一天的具体任务实例 |
| 幂等 | 同一操作重复执行，结果不会不断重复增加；例如同一模板一天只生成一个任务 |
| Service | 承载业务规则的 Python 函数模块，位于 `services/` |
| Model | 对数据或业务概念的代码表达；本项目 `models.py` 主要是常量和容量结果，不是 ORM |
| Repository | 专门封装数据库读写的一层；本项目目前没有独立 Repository，主要由 `database.py` 和 services 承担 |
| SQLite | 将整个本地数据库保存在单个文件中的数据库引擎 |
| Schema | 数据库表、字段、约束和关系的结构定义 |
| Migration | 在保留已有数据的前提下，把旧数据库结构升级到新版本 |
| Snapshot | 某一时刻的数据快照，像给目标拍照，之后原目标改变也不影响旧照片 |
| Session | 一次用户打开和使用应用的运行会话，关闭或重启后会结束 |
| Session State | Streamlit 在当前会话里暂存页面交互状态的内存，不是长期数据库 |
| Primary Key / 主键 | 一张表中唯一识别每条记录的字段，例如 `tasks.id` |
| Foreign Key / 外键 | 把一张表记录指向另一张表的字段，例如 `tasks.goal_id` |
| Streamlit | 当前用于同时构建 Python 页面和交互的 Web 应用框架 |
| 页面内提醒 | 应用打开并刷新时显示的提醒，不等于 Windows 系统通知 |
| 当前状态 | 代码和数据库今天真实支持的能力 |
| 目标状态 | 已确认要演进的产品方向，不代表已经完成 |
