# 产品路线图

路线图不承诺虚构日期。每个版本只解决一个明确问题，并在测试、手工验收和 Git 提交后结束。

## 当前版本：V0.2 数据安全与数据库稳定

已完成：

- `schema_migrations` 记录 Schema 版本、名称、校验值和时间；
- 已有数据库迁移前自动执行完整性检查和一致性备份；
- 新数据库初始化与旧数据库升级分离；
- 设置页可查看数据库版本和健康状态，并创建手工备份；
- 测试环境与真实 `growth.db` 隔离；
- 旧数据库、重复升级、备份、损坏数据库保护已自动测试。

尚未包含：自动恢复、Journal、Quick Capture、Goal History。

## P0 小版本顺序

1. V0.3：Goals / Direction 完全由用户输入和编辑。
2. V0.4：目标与方向历史版本。
3. V0.5：Quick Capture 与 Inbox。
4. V0.6：Daily Journal 一天一页。
5. V0.7：历史日记和日期切换。
6. V0.8：Today 统一整合系统、用户和临时任务。
7. V0.9：阅读、习惯、任务、复盘与当天 Journal 联动。
8. V0.10：任务和睡眠提醒稳定化。
9. V0.11：恢复演练、恢复入口与长期稳定性。

## V1.0

必须由真实连续使用至少 7 天证明，而不是由功能数量决定。期间需要验证数据不丢失、日记和历史可找回、任务统计正确、灵感和目标稳定、阅读与复盘不阻碍日常使用。

## P1：使用体验

日记搜索、周/月复盘、数据导出、更完整 Dashboard、灵感整理、目标进度、习惯/书籍完整管理和 UI 优化。

## P2：可选 AI

在用户明确授权和人工确认下，提供每日总结、周复盘、行为模式、延期原因、目标调整和计划建议。

## P3：长期探索

手机端、云同步、多端冲突处理、Personal Agent、MCP 和更完整的 Life OS。以上不是当前承诺。
