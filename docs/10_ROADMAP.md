# 产品路线图

路线图使用能力阶段而非虚构日期。进入下一阶段的前提是上一阶段稳定、可验证且确有用户价值。

## 当前：V1 基础闭环

已具备：

- 今日任务与快速建任务；
- 一次性任务和每日任务；
- 目标与方向基础管理；
- 习惯新增和打卡；
- 阅读记录；
- 每日结构化复盘；
- 基础统计、规划建议和页面内提醒；
- SQLite 本地持久化和核心自动化测试。

主要限制：复盘不等于完整日记、没有快速捕获收件箱、目标无历史、备份恢复依赖手工、部分统计和服务边界需修正。

## 下一阶段：V1.1 可靠性与数据主权

- 版本化数据库迁移；
- 可靠备份/恢复检查；
- 修复阅读统计与主任务选择；
- 清理 UI 文本问题和统一错误反馈；
- 默认内容改为中性引导，确保目标由用户定义。

完成标志：已有用户升级不丢数据，核心口径可信，基础流程回归通过。

## V1.2 捕获与日记闭环

- Quick Capture 收件箱；
- Daily Journal 保存、历史和搜索；
- 捕获转任务、转日记、归档；
- 与现有每日复盘平滑共存。

完成标志：用户从随手记录到晚间整理不需要借助外部工具，转换失败不丢原文。

## V1.3 目标演进与完整管理

- Goal History、变更原因和归档；
- 目标进度快照；
- 习惯编辑/停用/安全删除；
- 书籍新增/编辑/排序/归档。

完成标志：长期使用产生的变化可追溯，不需要直接操作数据库。

## V1.4 洞察与可携带数据

- 周复盘；
- 睡眠、习惯、阅读和目标趋势；
- 搜索与导出；
- 更易操作的备份工具。

完成标志：每项统计可解释、可追溯到原始记录，用户可以带走自己的数据。

## V2 可选智能能力

- 用户授权的数据总结；
- 目标拆解建议；
- 周复盘洞察；
- 可预览、可编辑、可确认的计划建议。

不做：让模型未经确认修改核心数据、把私人日记默认上传、用不透明评分替代用户判断。

## 远期评估项

只有出现明确需求时评估多设备同步、登录权限、远程 API、外部日历和 Agent 自动化。它们不是当前版本的承诺。
