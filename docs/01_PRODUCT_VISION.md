# 产品愿景

## 为什么存在

Personal Growth OS 不是因为世界上缺少 Todo 软件。真正的问题是：目标在脑子里，任务在 Todo，阅读在另一个 App，生活记录在日记，习惯又在 Habit Tracker。信息彼此断开后，用户很难回答：

> 我现在到底在往哪里走？我今天做的事情，真的支持这个方向吗？

## 产品使命

帮助一个人长期完成四件事：

1. 记录真实生活，而不只记录“完成了什么”。
2. 保持方向，知道当前最重要的问题是什么。
3. 执行重要事情，让目标落到今天。
4. 看见长期变化，从历史中理解自己的行为模式。

## 核心价值

- 方向感：长期目标、阶段目标与主要矛盾可见。
- 执行力：每天突出一件最重要的事，任务有验收标准。
- 完整性：学习、工作、生活、阅读、运动和睡眠在一个系统里。
- 连续性：每天的数据保存下来，不被下一次修改覆盖。
- 可理解：规则计划必须解释“为什么这样安排”。
- 可控性：用户决定目标和计划，系统辅助而不是替用户决定人生。

## 用户是谁

当前唯一优先用户是项目拥有者本人：正在学习 AI 应用开发，同时需要管理生活、成长和长期方向的个人用户。

当前产品约束：

- 单用户
- 本地运行
- 自用优先
- 数据真实和长期安全优先
- 新手可以理解和维护

## 不解决什么

- 不做企业团队协作和权限系统。
- 不做社交动态、排行榜和打卡社区。
- 不做 Jira 式复杂项目管理。
- 不追求替代所有笔记、日历和文件管理工具。
- V1 不让大模型自动控制目标、金额、数据删除或重要决策。
- 没有真实需求前，不引入微服务、Redis、消息队列和云数据库。

## 产品核心闭环

```text
长期方向
→ 阶段目标
→ 当前主要矛盾
→ 今天最重要的事
→ 任务与习惯执行
→ 记录真实生活
→ 每日复盘
→ 历史与统计
→ 调整下一阶段
```

## 最终产品形态

逐步成为 Personal Life OS / Personal Growth OS：一套以“一天一页”为中心、能快速收集想法、保留方向历史、连接行动与长期变化的个人系统。

## 成功标准

产品成功不以功能数量衡量，而以这些问题衡量：

- 用户是否每天愿意打开？
- 是否能在 30 秒内知道今天最重要的事？
- 临时任务是否不会遗漏？
- 灵感是否能在 5–10 秒内保存？（当前未实现）
- 今天与昨天的数据是否不会互相覆盖？
- 半年后是否能看见方向和行为的变化？（当前历史能力不足）
- 数据是否可以可靠备份与恢复？（当前仅支持手工复制）
