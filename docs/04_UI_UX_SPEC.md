# UI / UX 规格

## 1. 全局原则

- 首屏回答三个问题：今天最重要什么、还有多少容量、下一步做什么。
- 创建、保存、完成、顺延后必须给出成功或失败反馈。
- 当前功能正常展示；目标功能在实现前不得伪装成可点击入口。
- 默认数据只用于帮助理解，不应替用户长期决定人生方向。
- 空状态要告诉用户为什么为空，以及下一步可以做什么。
- 手机窄屏下优先保证核心操作可用，复杂表格允许纵向展开。

## 2. 导航与信息架构

当前导航：今日、目标与方向、任务、阅读、习惯、复盘、数据统计、设置。

目标导航可演进为：今日、快速捕获、任务、目标、习惯、阅读、日记与复盘、统计、设置。加入入口时应先完成底层数据和测试，避免空壳页面。

## 3. 今日页（当前）

**页面目标**：让用户在一分钟内决定今天先做什么。

**主要区域**：今日/明日快捷切换、日期查询、日期与问候、Focus、任务时间轴、快速添加、习惯条和日记复盘。

**用户操作**：切换今日计划或明日安排、按日期查询历史/未来、快速建任务、完成、编辑和习惯打卡。所见与保存始终绑定当前选中日期。

**状态设计**：

- 空状态：说明今天还没有任务，提供快速添加入口。
- 超载状态：明确显示预计分钟超过容量，并给出减少建议。
- 保存成功：即时提示并刷新列表。
- 错误状态：保留上下文，展示具体失败信息。

已知细节问题：部分 Markdown 文本残留转义字符，后续 UI 修复时应清理。

## 4. 任务页（当前）

**页面目标**：完整创建和管理一次性任务、每日任务。

**主要区域**：创建表单、筛选条件、任务列表、编辑区、每日任务模板列表。

**核心字段**：标题、说明、分类、优先级、日期、时间、预计分钟、验收标准、关联目标、是否必做、是否计入容量。

**交互要求**：

- “添加任务”和“添加每日任务”概念必须清晰区分。
- 停用每日任务只影响未来生成，不删除过去的任务记录。
- 删除一次性任务前应有明确提示；目前实现仍需后续加强确认体验。

## 5. 目标与方向页（当前，历史能力为目标）

**页面目标**：表达长期方向，并把目标拆为可关联任务的层级。

**当前区域**：方向编辑、目标创建/编辑、目标层级与进度。

**目标增强**：目标历史、变更原因、归档、进度快照。

**空状态**：引导用户先写一句长期方向，再创建第一个阶段目标；不应强迫采用预置职业方向。

## 6. 习惯页（当前）

**页面目标**：添加习惯并记录当天执行情况。

**主要区域**：新增习惯按钮/表单、今日习惯卡、分钟与备注、连续天数。

**当前边界**：支持新增和打卡；不支持编辑、删除、停用。目标版本应补齐这些管理操作，并对删除历史日志提供保护。

## 7. 阅读页（当前）

**页面目标**：维护阅读进度，记录阅读投入与认知收获。

**主要区域**：书单、进度、状态管理、阅读记录表单。

**当前边界**：默认书单较完整，但缺少新增、删除和排序入口；`today_minutes` 的统计口径需要修正，不能无限累计后仍称“今日”。

## 8. 复盘 / Daily Journal（部分实现）

**当前页面目标**：保存某一天的结构化复盘。

**当前区域**：事件、主任务、收获、问题、状态、时间浪费、明日任务、自由文本。

**目标页面能力**：

- 日历或列表浏览历史日记；
- 自动保存或明确保存状态；
- 全文搜索和标签；
- 从快速捕获内容整理进日记；
- 区分“事实记录”和“复盘结论”。

当前没有独立 `journal_entries` 数据模型，因此 UI 上应继续称“复盘”，直到数据模型完成。

## 9. 快速捕获（目标，未实现）

**页面目标**：三秒内保存任何未分类内容，不打断当前工作。

**建议区域**：单输入框、最近捕获、未处理收件箱、转任务/转日记/归档操作。

**关键状态**：输入为空时禁用保存；成功后清空输入并显示时间；转换失败时原始捕获不能丢失。

## 10. 数据统计（当前基础版）

**页面目标**：用少量指标帮助调整行为，而不是制造数据压力。

**当前指标**：任务完成情况、分类统计、投入分钟、学习连续天数。

**目标指标**：睡眠和习惯趋势、阅读趋势、目标进展、周复盘。每个图表都必须注明统计范围和口径。

## 11. 设置页（当前）

**页面目标**：配置可支配时间、提醒时间和主题偏好。

**状态设计**：保存后明确提示；非法时间不能写入；尚未生效的设置不应出现在 UI。

## 12. 通用验收标准

- 所有提交按钮都有成功、失败和重复点击保护。
- 所有列表都有空状态。
- 所有日期、分钟和百分比口径一致。
- 键盘可以完成主要表单操作。
- 删除或覆盖重要内容时，用户知道影响范围并有恢复路径。

## 13. 逐页状态矩阵

| 页面 | 主要数据展示 | 空状态 | 保存状态 | 错误状态 |
|---|---|---|---|---|
| Today | 当日任务、主任务、容量、习惯、提醒 | 引导创建今天第一项任务 | 创建/完成/顺延后提示并刷新 | 保留当前任务上下文，说明失败动作 |
| Journal（目标） | 一日一页、历史列表、关联捕获 | 引导写今天第一句话 | 显示保存中、已保存和最后时间 | 草稿不丢失，允许重试 |
| Goals | 方向、层级目标、当前重点和进度 | 引导用户自己写方向，不自动替用户决定 | 明确提示方向或目标已保存 | 指出字段或数据库错误，不覆盖旧值 |
| Tasks | 筛选后的任务、每日模板 | 展示创建入口和示例字段说明 | 显示任务/模板保存成功 | 非法时间、空标题、重复模板给出具体原因 |
| Quick Capture（目标） | 未整理捕获和创建时间 | 说明收件箱为空，输入框仍保持突出 | 保存后立即清空输入并出现新记录 | 原文字保留，转换失败可重试 |
| Books | 书单、进度、阅读历史摘要 | 引导新增书籍（该入口当前尚未实现） | 阅读日志保存后刷新进度 | 页数/分钟非法或书籍冲突时说明原因 |
| Habits | 当日打卡、分钟、连续天数 | 引导点击新增习惯 | 打卡后即时反馈 | 重复名称和非法分钟不写入 |
| Review | 指定日期的结构化复盘 | 空表单并说明可自由选填 | 保存后显示日期和成功状态 | 保留已输入文字，不能显示假成功 |
| Dashboard | 日期范围内统计和指标口径 | 说明尚无足够数据 | 无写操作 | 聚合失败时不显示误导性的零值 |
| Settings | 容量、时间和界面偏好 | 使用中性默认值 | 显示已保存及生效范围 | 非法时间保留旧设置 |
